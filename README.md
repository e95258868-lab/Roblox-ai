# 🤖 Roblox AI Assistant

Roblox için geliştirilmiş, AI destekli Chrome uzantısı.

---

## 🇹🇷 Türkçe

### 📦 Kurulum

1. Bu GitHub reposunu bilgisayarına indirin.
2. ZIP dosyasını çıkartın.
3. Chrome'u açın.
4. Adres çubuğuna şunu yazın:

```text
chrome://extensions/
```

5. Sağ üstten **Geliştirici modu** seçeneğini açın.
6. **Paketlenmemiş öğe yükle** butonuna tıklayın.
7. Projedeki `extension` klasörünü seçin.
8. Uzantı Chrome'a eklenmiş olacaktır.

### 🔄 Güncelleme

Kodda değişiklik yaptıktan sonra:

**chrome://extensions/** → uzantınızı bulun → **Yenile ↻**

---

## 🇬🇧 English

### 📦 Installation

1. Download this GitHub repository to your computer.
2. Extract the ZIP file.
3. Open Chrome.
4. Enter the following address:

```text
chrome://extensions/
```

5. Enable **Developer mode** in the top-right corner.
6. Click **Load unpacked**.
7. Select the project's `extension` folder.
8. The extension will now be installed in Chrome.

### 🔄 Updating

After making changes to the code:

**chrome://extensions/** → find the extension → click **Reload ↻**
